01 / About

Sobre mí

Soy Roberto, desarrollador de Aplicaciones Multiplataforma (DAM) centrado en construir productos completos: desde la app nativa en Kotlin hasta el backend y el panel de administración.

Me muevo cómodo entre Java, Kotlin y Android SDK para el desarrollo móvil, y entre JavaScript, React y SQL para construir la capa web y de datos.

Firebase y Git forman parte de mi flujo diario: control de versiones disciplinado y servicios en la nube para autenticación, base de datos en tiempo real y notificaciones push.
